# Enterprise Architecture Discovery Framework

**Kedudukan:** BUKAN bagian dari CECEP. Berisi 29 dokumen (eks Phase G-L CECEP) yang, menurut [`CECEP/29-context-integrity-audit.md`](../CECEP/29-context-integrity-audit.md) dan [`CECEP/31-adr-cecep-framework-separation.md`](../CECEP/31-adr-cecep-framework-separation.md), ditemukan berevolusi menjadi metodologi arsitektur generik — bukan lagi spesifik Construction Cost Engineering. Dipindahkan secara fisik ke direktori ini (bukan hanya dinyatakan dipindah) sesuai Follow-up Action `31` yang sebelumnya belum dieksekusi.

**Isi:** Metodologi Discovery/Synthesis/Projection, Rule Meta Model, Integration Ontology (Titik Serah/Uncertainty Window), AI ontology (definisi umum "apa itu AI"), Design Space/epistemic framework, Relation Algebra/Asset Relationship Graph.

**Status Capability Catalog di dalamnya:** Dokumen `08`-`08k` dan turunannya memakai Capability Catalog CAP-001 s.d. CAP-013 yang SUDAH USANG (digantikan `CECEP/35`). Kalau Framework ini suatu saat dipakai lagi (untuk modul Puraloka Suite lain — Procurement, HR, CRM), Capability Catalog di dalamnya perlu diderivasi ulang dari nol untuk domain baru itu, BUKAN diwarisi apa adanya.

**Nilai reusable:** Ditulis untuk CECEP tapi generik — berpotensi dipakai modul Puraloka Suite lain yang butuh Rule Engine, Integration pattern generik, atau kerangka epistemic serupa. Belum ada proyek yang secara resmi mengklaim/memakai Framework ini pasca-pemisahan — status "belum dipakai kembali", bukan "sedang dipakai".

**Tidak dirujuk sebagai evidence otoritatif oleh dokumen CECEP manapun** (`CECEP/32`-`52`) — konsisten `40`/`41` (Architecture Derivation Constitution, Evidence Hierarchy).
